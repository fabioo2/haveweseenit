# Have We Seen It?

A movie and TV tracker for two people, backed by a Google Sheet.

<img width="505" height="700" alt="Screenshot of the app" src="https://github.com/user-attachments/assets/14ff6071-c1f5-4a8e-9a58-acb2fda8811b" />

Live at <https://fabioo2.github.io/haveweseenit/>

## Features

- Search movies and TV shows via [TMDB](https://www.themoviedb.org/) and add them to a shared list
- Per-person watched status, 1–10 ratings and, for series, seasons watched
- Filter by person, language and genre; sort by date, rating, title or language
- A public page listing everything either person rated 9 or higher
- Light and dark mode

## Tech stack

- [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/), built with [Vite](https://vite.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/) and [shadcn/ui](https://ui.shadcn.com/) (Base UI)
- [TanStack Query](https://tanstack.com/query) for server state, [Zustand](https://zustand.docs.pmnd.rs/) for UI state
- [Google Apps Script](https://developers.google.com/apps-script) + Google Sheets as the backend ([`apps-script/`](apps-script/))
- Hosted on GitHub Pages

## Getting started

Requires Node 22+.

```bash
npm install
cp .env.example .env.local   # then fill in both values
npm run dev
```

| Variable | Description |
| --- | --- |
| `VITE_TMDB_TOKEN` | TMDB API read access token (v4) |
| `VITE_SCRIPT_URL` | Apps Script web app URL, ending in `/exec` |

Both values are embedded in the built bundle and are not secrets. The only
secret is the passphrase, which is stored in the Apps Script project and never
in this repo. See [`apps-script/README.md`](apps-script/README.md) for how
authentication works.

## Project structure

```
src/
  pages/        Top-level screens (list, public page, passphrase)
  components/   UI components; components/ui/ is generated by shadcn
  hooks/        Data and UI hooks
  store/        Zustand stores
  lib/          API clients, types and helpers
apps-script/    Backend (Google Apps Script)
```

## Deployment

Pushing to `main` builds and deploys to GitHub Pages via
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

Repository settings:

- **Settings → Pages → Source:** GitHub Actions
- **Settings → Secrets and variables → Actions:** secret `VITE_TMDB_TOKEN`, variable `VITE_SCRIPT_URL`

`base` in [`vite.config.ts`](vite.config.ts) must match the repository name.
